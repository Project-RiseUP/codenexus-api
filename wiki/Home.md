## 🔗 CodeNexus API

**Unified REST API for competitive programming and developer profiles.**

- **One API, 6 Platforms**
- **Real-time data, unified format**
- **Minimal logging, production-ready**

### 📦 What This API Does

- Aggregates profile data from:
  - LeetCode, Codeforces, CodeChef
  - GeeksforGeeks, HackerRank, GitHub
- Normalizes them into a **consistent JSON schema**
- Exposes everything via simple REST endpoints
